# 免费前三集交付标准

## 1. 文档目标

免费前三集不是传统意义上的样章，而是用户第一次真实制作和市场验证的启动包。

它需要同时完成三件事：

1. 让用户看懂这套剧本值不值得做。
2. 让用户可以直接拿去制作前三条视频。
3. 让用户发布后能用数据判断是否继续购买或合作。

因此，免费包不能只给剧情简介，也不能只给几段分镜。它必须是一个完整的“验证单元”。

## 2. 免费包定位

免费包的定位是：

- 免费领取。
- 可直接制作前三集。
- 可发布测试。
- 不包含第4集及以后内容。
- 不转让完整版权。
- 不允许二次售卖、转发打包或作为资源包分发。

用户拿到免费包后，应当能在最短时间内完成：

1. 理解剧本卖点。
2. 生成前三集视频素材。
3. 剪辑并发布。
4. 观察数据。
5. 决定是否继续做第4集。

## 3. 免费包标准目录

每套剧本的免费包建议包含以下文件或模块：

| 模块 | 作用 | 是否必需 |
| --- | --- | --- |
| 剧本概览 | 让用户快速判断题材和受众 | 必需 |
| 前三集正文 | 直接用于配音、字幕、剪辑 | 必需 |
| 前三集分镜 | 直接用于画面生成或拍摄 | 必需 |
| 角色视觉锚点 | 保证人物画面一致性 | 必需 |
| 画面提示词 | 投喂 AI 视频或图片工具 | 必需 |
| 标题与封面建议 | 帮用户提高测试成功率 | 必需 |
| 发布测试指南 | 告诉用户看哪些数据 | 必需 |
| 授权边界说明 | 防止免费内容被误用 | 必需 |
| 续作入口说明 | 引导买断、按集、分成 | 必需 |

## 4. 剧本概览标准

剧本概览用于用户在5分钟内判断这套剧是否适合自己的账号。

必须包含：

- 剧本名称。
- 一句话爆点。
- 类型标签。
- 目标受众。
- 推荐平台。
- 推荐画幅。
- 预计总集数。
- 前三集验证目标。
- 适合的账号类型。
- 不适合的账号类型。

示例结构：

```md
剧本名称：她闻到谎言
一句话爆点：女主能闻到谎言，每一次气味变化都代表一层真相反转。
类型标签：现代悬疑、都市商战、情感拉扯、豪门旧案、女性向反转
推荐平台：抖音、快手、小红书、TikTok、YouTube Shorts
前三集验证目标：测试“特殊能力 + 豪门旧案 + 男主嫌疑”是否能引发追更。
```

## 5. 前三集正文标准

每一集都要提供可以直接进入制作的正文，而不是只有梗概。

每集正文应包含：

- 集数标题。
- 本集时长建议。
- 本集核心钩子。
- 场景说明。
- 角色出场。
- 旁白或字幕文案。
- 关键对白。
- 结尾悬念。
- 下一集追更点。

### 单集正文模板

```md
## 第1集：标题

时长建议：45-75秒

核心钩子：
用户前三秒必须知道这集最吸引人的点。

场景：
说明主要空间、时间、氛围。

出场角色：
- 角色A：本集状态。
- 角色B：本集状态。

剧情正文：
按可拍摄顺序写清楚行动、对白、字幕和情绪变化。

结尾悬念：
本集最后必须留下一个明确问题。

下一集追更点：
用户为什么会想点开第2集。
```

## 6. 前三集分镜标准

分镜是免费包里最关键的可制作资产。每集建议提供6-10个核心镜头，不追求面面俱到，但必须覆盖完整叙事节奏。

每条分镜应包含：

- 镜头编号。
- 画面内容。
- 角色动作。
- 镜头运动。
- 光线和氛围。
- 音效或音乐建议。
- 字幕或对白。
- AI画面提示词。

### 分镜模板

```md
### 镜头 01

画面内容：
深夜会议室，窗外雨夜霓虹，女主合上委托文件。

角色动作：
女主准备拒绝委托，忽然闻到男主身上的特殊气味。

镜头运动：
从文件特写慢慢上摇到女主眼睛。

光线氛围：
冷蓝色电脑光，人物脸部半明半暗。

字幕/对白：
“这个味道……我只在母亲失踪那晚闻到过。”

AI提示词：
竖屏短剧，现代都市悬疑，深夜会议室，雨夜霓虹，冷蓝色光线，女主清冷克制，电影感特写，高反差光影。
```

## 7. 角色视觉锚点标准

前三集必须给出主要角色的稳定视觉设定，避免用户生成视频时角色漂移。

每个主要角色应包含：

- 中文姓名。
- 英文或拼音标识，可用于提示词。
- 年龄段。
- 外貌关键词。
- 服装关键词。
- 情绪气质。
- 标志性物件。
- 禁止变化点。

### 角色模板

```md
### 苏清妤

角色定位：危机公关顾问，女主。
年龄段：28岁。
外貌关键词：亚洲女性，清冷精致，黑色齐肩微卷发。
服装关键词：象牙白真丝衬衫，黑色高腰西装裤，细框金属眼镜。
气质关键词：冷静、克制、敏锐、不轻易暴露情绪。
标志性物件：旧银色小项链。
禁止变化点：不要换成甜美少女感，不要变成夸张网红妆。
```

## 8. AI提示词标准

提示词要分成两类：基础角色提示词和单镜头提示词。

### 基础角色提示词

用于保持人物一致性，应包含：

- 角色固定外貌。
- 固定服装或主色系。
- 固定气质。
- 固定年龄段。
- 镜头风格限制。

### 单镜头提示词

用于生成具体画面，应包含：

- 画幅。
- 场景。
- 角色。
- 动作。
- 光线。
- 镜头。
- 风格。
- 情绪。

建议采用中英双语，方便国内和海外工具使用。

提示词不应过度堆词。每条提示词要服务一个明确画面，不要把所有风格词一次性塞进去。

## 9. 标题与封面建议

免费包必须帮助用户提高前三集测试成功率，因此每集至少提供3个标题方向和2个封面方向。

### 标题方向

标题可以围绕：

- 特殊能力。
- 反转冲突。
- 情感拉扯。
- 豪门秘密。
- 生死悬念。
- 追更问题。

示例：

- “她能闻到谎言，却在他身上闻到了母亲失踪那晚的味道”
- “豪门继承人开价千万，她却发现他可能和旧案有关”
- “她刚想拒绝委托，下一秒闻到了最不该出现的味道”

### 封面方向

封面建议应包含：

- 主视觉人物。
- 冲突文字。
- 情绪关键词。
- 画面色调。
- 避免事项。

示例：

```md
封面方向1：女主冷脸特写 + 雨夜会议室背景
封面文字：他身上有旧案的味道
情绪：怀疑、压迫、危险靠近
避免：不要做成普通霸总甜宠封面
```

## 10. 发布测试指南

用户领取免费包后，应该知道如何测试，而不是只知道怎么制作。

建议给用户一个简单测试方法：

### 发布节奏

- 连续发布前三集。
- 每集间隔建议为6-24小时。
- 如果第1集数据明显异常好，可以加快第2集发布。
- 如果第1集数据一般，第2集标题和封面可以换角度再测。

### 观察指标

重点看：

- 3秒留存：判断开头钩子是否成立。
- 完播率：判断单集节奏是否成立。
- 评论区追更：判断剧情是否有连续性。
- 收藏和转发：判断题材是否有传播价值。
- 涨粉：判断账号受众是否匹配。
- 私信和咨询：判断商业转化意愿。

### 初步判断标准

可以给用户一个粗略判断框架：

| 数据表现 | 判断 | 建议动作 |
| --- | --- | --- |
| 播放一般，但评论催更明显 | 剧情有潜力，包装需优化 | 继续测第2、第3集 |
| 播放高，完播高，催更多 | 值得继续 | 购买第4集或小包 |
| 播放高，完播低 | 开头有效，节奏需压缩 | 调整剪辑再测 |
| 播放低，完播低 | 题材或包装不匹配 | 换标题封面或换剧本 |
| 涨粉明显 | 账号适配度高 | 考虑买断或连续更新 |

## 11. 用户回传数据标准

为了后续转化和分成合作，建议引导用户回传前三集数据。

用户可回传：

- 发布平台。
- 账号名称或链接。
- 每集视频链接。
- 播放量。
- 点赞量。
- 评论量。
- 完播率。
- 涨粉量。
- 收益截图，如果已有收益。
- 用户自己的判断和问题。

回传目的：

- 判断是否适合买断。
- 判断是否适合按集续购。
- 判断是否有资格进入分成合作。
- 帮用户优化标题、封面、剪辑节奏。

## 12. 授权边界说明

免费前三集授权建议写得简短、明确、放在免费包末尾和领取页面。

建议表达：

```md
你可以使用本免费包制作并发布前三集测试视频。
本免费包不包含第4集及以后内容授权，不构成完整剧本版权转让。
你不得将本免费包转售、打包上传、拆分售卖或作为素材库二次分发。
如果你希望继续制作第4集及后续内容，请选择一次性买断、按集付费或版权分成合作。
```

## 13. 续作转化入口

免费包末尾必须清楚告诉用户下一步怎么走。

建议放三个入口：

### 入口1：一次性买断

适合已经验证出明显数据、希望连续更新的用户。

按钮或话术：

```md
我想一次性拿到完整剧本
```

### 入口2：按集付费

适合数据有潜力但还想继续观察的用户。

按钮或话术：

```md
我想先购买第4-8集
```

### 入口3：版权分成

适合有账号运营能力、不想提前支付剧本费用的用户。

按钮或话术：

```md
我想申请分成合作
```

## 14. 免费包制作流程

每套剧本上架前，按以下顺序制作免费包：

1. 提取剧本概览。
2. 整理前三集核心钩子。
3. 写完整前三集正文。
4. 为每集拆6-10条核心分镜。
5. 提取主要角色视觉锚点。
6. 编写基础角色提示词。
7. 编写每条分镜提示词。
8. 为每集准备标题和封面建议。
9. 写发布测试指南。
10. 添加授权边界和续作入口。
11. 检查是否泄露第4集及以后关键反转。
12. 打包成用户可领取版本。

## 15. 质量检查清单

发布免费包前逐项检查：

- 前三集是否可以独立制作成视频。
- 每集是否有明确开头钩子。
- 每集结尾是否有追更问题。
- 分镜是否覆盖完整叙事。
- AI提示词是否足够具体。
- 角色视觉是否稳定。
- 标题是否有点击理由。
- 封面是否有冲突和情绪。
- 用户是否知道如何发布测试。
- 用户是否知道看哪些数据。
- 授权边界是否清楚。
- 第4集以后内容是否没有被完整泄露。
- 续作入口是否明显。

## 16. 与现有 JSON 的对应关系

当前项目里的 `product-template.json` 和 `storyboard.json` 可以作为免费包的数据来源。

建议对应方式：

| 免费包模块 | 可对应 JSON 内容 |
| --- | --- |
| 剧本名称 | `product_metadata.title` |
| 一句话爆点 | `story_package.core_hook` 或 `product_metadata.logline` |
| 类型标签 | `story_package.genre_tags` |
| 推荐平台 | `product_metadata.recommended_platforms` |
| 前三集钩子 | `story_package.first_three_episode_hooks` |
| 角色视觉锚点 | `characters.visual_anchor` 或 `storyboard.scenes.characters.visual_anchor` |
| 分镜 | `storyboard.scenes` |
| 画面提示词 | 可由场景、角色、动作、镜头、光线组合生成 |
| 销售说明 | `sales_page` 中的卖点可重写为免费验证话术 |

后续如果要改代码，可以先让数据结构支持：

- `free_preview_package`
- `free_preview_episodes`
- `preview_license`
- `test_guidance`
- `continuation_options`
