## 8. AI制作提示

### 推荐工具

用户可以根据自己的工作流选择：

- 文生图工具：【待填写，例如 Midjourney / 即梦 / 可灵 / 其他】
- 图生视频工具：【待填写，例如 Runway / 可灵 / Sora / 其他】
- 剪辑工具：【待填写，例如 剪映 / CapCut / Premiere】
- 配音工具：【待填写】

### 画面统一建议

- 全部视频建议使用 9:16 竖屏。
- 同一角色尽量固定服装、发型、年龄段和主色调。
- 每集开头 3 秒必须给出强冲突、特殊能力、危险关系或悬念问题。
- 每集结尾要停在“观众想知道下一步”的位置。
- 不要把第4集及以后关键反转提前做进前三集。

### 剪辑节奏建议

- 前3秒：直接给冲突或异常信息。
- 第4-20秒：快速建立人物关系和危险处境。
- 第21-45秒：推进线索或反转。
- 最后5-10秒：抛出悬念，留下追更问题。

## 9. 发布测试指南

### 建议发布节奏

| 集数 | 建议动作 |
| --- | --- |
| 第1集 | 先发最强钩子版本，观察3秒留存和完播 |
| 第2集 | 根据第1集评论区调整标题或封面角度 |
| 第3集 | 重点观察追更、涨粉和私信咨询 |

### 建议观察指标

| 指标 | 看什么 | 说明 |
| --- | --- | --- |
| 3秒留存 | 开头是否抓人 | 低则需要重做开场 |
| 完播率 | 单集节奏是否成立 | 低则需要压缩铺垫 |
| 评论区 | 是否有人催更、猜剧情、站角色 | 判断连续剧潜力 |
| 收藏转发 | 题材是否有传播价值 | 判断内容是否有复看和分享价值 |
| 涨粉 | 账号受众是否匹配 | 判断是否值得连续更新 |
| 私信咨询 | 是否有人主动问后续 | 判断商业转化意愿 |

### 简单判断

| 数据表现 | 结论 | 下一步 |
| --- | --- | --- |
| 播放一般，但评论催更明显 | 有剧情潜力，包装需优化 | 改标题封面，继续测 |
| 播放高，完播高，催更多 | 值得继续 | 购买第4集或咨询买断 |
| 播放高，完播低 | 开头有效，节奏需压缩 | 重剪前三集 |
| 播放低，完播低 | 账号或题材不匹配 | 换包装或换剧本 |
| 涨粉明显 | 账号适配度高 | 考虑连续更新 |
